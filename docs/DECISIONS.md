# Frogue Gallery — Decision Log

Only consequential technical/product decisions that a future agent must
understand. One entry per decision; newest last. Status: active / superseded.

| # | Date | Decision | Rationale | Status |
|---|---|---|---|---|
| 1 | 2026-09 | **Zero dependencies, no build step.** Vanilla JS ES modules, Canvas 2D, Web Audio; served by `python -m http.server 8765`. | A compact, inspectable, single-repo game; no supply chain; trivially portable. | active |
| 2 | 2026-09 | **Pure rule logic isolated in `src/logic.js`.** Save schema, migrations, balance, and economy are browser-free and unit-tested via `tests/smoke.mjs`. | The only CI is the smoke suite; pure logic keeps it fast, deterministic, and browser-free. | active |
| 3 | 2026-09 | **Painting is the combat system.** Red/blue/green pigments = damage+burn / slow→freeze / root+heal; dry brush is a 50%-damage fallback, never a softlock. | Core design pillar; status fields live on the paint surface (`paint.js`) and are read by enemies. | active |
| 4 | 2026-09 | **Boss fight = 30,000 HP heron, ~2.3 min human / ~37 s bot ceiling.** World widened 2400→5400 px with 4 named zones + rest checkpoints (P5). | DoD #9 requires a satisfying 15–20 min run; the boss had to be a real fight, not a bar to chip. | active |
| 5 | 2026-09 | **Balance for a taught first-time player:** maxHp 7→10, beetle/toad contact 8/9→6, greenHeal 1→3 (P4). | The tutorial (P1) means players arrive competent; early game must not one-shot them. | active |
| 6 | 2026-09 | **localStorage with migration + safe fallback.** All keys prefixed `frogue_gallery_`; `migrateSave` defaults/merges missing fields; load failure → fresh save, never a boot crash. | DoD #11: corrupted/old saves must fail safely or migrate. | active |
| 7 | 2026-09 | **Loopback-only server, browser-local data.** No cloud LLM APIs, no remote services, no external accounts; `uv` for any Python env, never `pip`. | Mission safety/environment boundary. | active |
| 8 | 2026-09 | **Post-release v1.1 = bug fixes (M7) then improvements (M8); deferred extras (gold pigment, gamepad, NG+, CRT) explicitly out of scope.** | Release DoD is satisfied; keep v1.1 tight and shippable. | active |
| 9 | 2026-09 | **P12 "signature encounter" = a scaled elite of the zone's emblematic enemy, not a new species.** `ELITE = {hp:1.9, dmg:1.3, radius:1.35, score:3}`, ringed in a per-zone accent + a 2.6s fading accent wash on entry. | A new enemy archetype would need AI + art + a smoke stage and risk a difficulty spike; an elite reuses existing behavior/art and adds place-identity ("character") cheaply. 1.9× HP stays a couple of swipes so zones add set-pieces, not walls (pace probe 18.7 min, in target). | active |
| 10 | 2026-09 | **P7 difficulty (Gentle/Normal/Bold) scales boss HP, enemy HP, and damage-taken — not paint/economy. Normal is byte-for-byte the released tuning.** `applyDifficulty()` in `logic.js` after loadout modifiers; choice persisted in `options.difficulty`. | The three levers that change difficulty most are boss/enemy toughness and how hard the frog takes hits; leaving pigment roles and the economy alone keeps Normal the reference balance and the tiers honest (Gentle 0.75×, Bold 1.35×). Persisted in options so a run starts where the player left the title. | active |
| 11 | 2026-09 | **P8 Gallery Wall = a display-only third Atelier tab, not a re-skin of the Paintings tab.** Every painting hung in a frame; owned = lit + placard + "★ hung", unowned = dimmed silhouette, sealed = "???". Buying/hanging stays on the Paintings tab. | A wall that could also buy would duplicate the Paintings click map and risk the two drifting apart; a pure display tab reuses the existing art motifs + a single frame renderer, adds a "my collection" moment (v1.1 wanted the owned art to *mean* something), and costs no new rows in `_atelierRows`. | active |
| 12 | 2026-09 | **K4 The Gilded Heron (v1.5): NG+ cycle-3+ 3rd boss — gold palette, 42k HP, and a *plume* phase that ABSORBS the frog's green heal sources (paint-on-green + standing-in-green both suppressed) while live; a boss-side 10s-active / 20s-gap phase timer (no hold, unlike the green heron's reed pin). Pure `GILDED_HERON` + `gildedPlumeTick`/`gildedPlumeActive` in `logic.js`; a per-frame `player._plumeSuppress` flag gates both heal sites.** | Reuses `bossStep`/`paintBoss`/`paintBossHit` end-to-end; the plume forces *heal management* (heal in the gap) rather than a new damage window, so it is a player-skill mechanic, not a session-length extender (the green heron's 2× pin bonus offsets the +6k HP → cycle-3 total unchanged at ~27 min). | active |
| 13 | 2026-09 | **The Gilded Heron awards NO new meta gold (`GOLD.boss.gilded: 0`; `goldTotal()` stays 67; no gold event).** | The gilded heron is a *later-cycle NG+ escalation* of the NG+ boss (the player already banked the green heron's 20 gold in cycle 1); adding a 3rd gold event would bloat the 67-gold career economy for a repeatable cycle. Keeps the G1 economy stable. | active |
| 14 | 2026-09 | **NG+ cycles 2-3 run LONGER than the 15-20 min band by design (~23 / ~27 min).** The 15-20 min band is the FIRST-TIME / cycle-1 reference; the per-cycle `NG_STEPS` escalation (HP/dmg/spawn +30/+15/+10 per step, capped at cycle 3) outgrows the returning-player efficiency on the dominant wave-fighting leg. The default `ngpace.mjs` run (cycle 1, ~19.5 min) is the green CI gate; `NG_CYCLE=2/3` runs are informational. | An NG+ cycle that also had to fit 15-20 min would make NG+ *easier* than a first-time run, which defeats the point. The band protects the *first* experience; escalation is the *return* experience. (K6 adds a cycle-4+ "Master" tier on top.) | active |
